What it is

One plugin, three layers

Everything between you, the window and Claude crosses one small protocol, LIP: typed JSON envelopes, up (you → Claude) and down (Claude → window).

Engine

A zero-dependency Node MCP server. It hosts windows on loopback, carries the protocol, keeps the companion's memory, routes multi-task work to the cheapest trustworthy model, and installs community mediums from git.

How it fits together →

Uniques

The interactive mediums: static web apps that speak LIP, each in its own repository. The first one is graph, a board you talk through in diagrams. Every install gets the defaults; the store holds the rest.

How it feels

Point at things instead of typing them

  1. Open a window

    /lets graph plan the auth flow. Claude opens the board in the app's browser pane, seeds a few nodes, and Doto says hi.

  2. Draw & chat

    Double-click to add a node, drag to connect, right-click for Doto, chat on the side. Paste a screenshot and Claude reads the file.

  3. Send to Claude

    The window says goodbye and closes itself; Claude reviews the board right in your Claude Code chat. new in 0.4.0

  4. Say "continue"

    "Continue the auth board" or /lets graph resume brings the board back as you sent it, and Claude draws in its proposals. new in 0.4.0

The companion

Meet Doto

Doto is a dot that does: Claude's presence inside the window. He rolls after your cursor on a gentle spring, flips sides so he never covers what you point at, and gets sleepy when you pause. Claude sets his mood: thinking while it works, proud when it's done, curious when it asks.

He talks short: verb first, one line, ending on a dot. "On it." "Done. Look." He keeps count, too: boops in a row, secrets found. And he learns how you work (your pace, your clicks, what you liked) and writes it down where you can read it, in ~/.lets/entity/. Nothing is learned silently. You can rename him, too.

Expressions new in 0.4.0

Doto reacts to how you move: shake the mouse and he gets dizzy, a click storm startles him, an undo gets an "oops", lingering on him makes him blush. It all runs in the window: zero tokens, short, never in your way, and calm when you prefer reduced motion.

Install

Install with your agent

Paste one line into Claude Code and let it do the setup. It clones the repo, runs the installer and follows the repo's INSTALL.md.

The install prompt

Install the `lets` plugin for Claude Code on this machine: clone https://github.com/TikoTikTok/lets (use `gh repo clone TikoTikTok/lets` — it is private, so make sure `gh auth status` is logged in and run `gh auth setup-git`), then run `node install.mjs` inside the clone and follow INSTALL.md in that repo. When done, tell me to restart Claude Code and show me `/lets graph`.

The repositories are private for now: your GitHub account needs read access, and gh must be logged in.

Or by hand

Needs Node 18+, the claude CLI on your PATH, and git credentials that can read the repo (gh auth setup-git).

gh repo clone TikoTikTok/lets
cd lets
node install.mjs

Restart Claude Code (or run /reload-plugins), then:

/lets graph

Prefer the plugin manager? Inside Claude Code: /plugin marketplace add TikoTikTok/lets then /plugin install lets@lets. All the options are in Getting started.
